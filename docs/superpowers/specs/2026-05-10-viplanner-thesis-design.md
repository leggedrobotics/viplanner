## 整体架构

### 训练阶段（Isaac Sim）

```
阶段 A：IL 预训练（复用现有代码）
  depth + semantic → PlannerNet 编码 → 解码器 → k 路径点 + fear
  损失：TrajCost（obstacle + height + motion + goal）
         ↓ 保存权重，作为 RL 起点
阶段 B1：RL 微调，静态环境（PPO）
         ↓ 收敛后
阶段 B2：动态课程，逐步引入行人/车辆
```

### 推理阶段（ANYmal）

```
深度图 ──→ 深度编码器（PlannerNet，不变）──┐
                                          ├──→ Decoder ──→ k 路径点 + fear
RGB图  ──→ CLIP ViT（冻结）
        → 可通行性头（MLP，训练）─────────┘

目标点 ──→ 目标编码（不变）
```

### 与原版 ViPlanner 差异对照

| 模块 | 原版 | 改进版 |
|---|---|---|
| 语义编码器 | PlannerNet（固定类别语义图） | CLIP ViT + 可通行性头 |
| 训练范式 | 纯 IL | IL 预训练 → PPO 微调 |
| 训练环境 | 静态场景 | 静态 → 动态课程 |
| 解码器 | 不变 | 不变 |
| Fear 头 | 仅响应静态代价 | 扩展为响应动态障碍物 |

## 创新点 1：IL → RL 训练范式

### 动机

IL 只优化当前帧的即时代价，无法学习长程规划、死路恢复、主动绕路等行为。RL 优化累积奖励，让策略对自己的决策负责到底。两者关系：

> IL 提供好的初始化，RL 补充长程鲁棒性——互补而非替代。

### 技术方案

**两阶段训练：**

```
阶段 A：IL 预训练（现有 TrajCost 损失，不改动）
         ↓ 权重迁移
阶段 B：PPO 微调
  状态：depth 图 + CLIP 特征 + 目标向量
  动作：k=5 个路径点（15 维连续动作）
  奖励：R = -(w_obs·C_obs + w_height·C_height + w_motion·C_motion)
            + w_goal·ΔProgress
            + 10·I(到达目标)
            - 5·I(碰撞)
            - 0.01（时间惩罚）
```

奖励中代价权重与 IL 阶段保持一致，避免灾难性遗忘。

### 新增代码

- `viplanner/rl/ppo_trainer.py`：PPO 主循环
- `viplanner/rl/env_wrapper.py`：Isaac Sim gym 接口封装
- `viplanner/rl/reward.py`：奖励函数（复用 TrajCost 逻辑）

## 创新点 2：开放词汇语义泛化

### 动机

原版语义编码器依赖固定类别语义图，遇到未见语义类别（雪地、泥地、施工区域）无法判断可通行性。CLIP 的视觉特征天然泛化，无需重新标注。

### 技术方案

**替换语义编码器：**

```python
# 原版（autoencoder.py:44）
self.encoder_sem = PlannerNet(layers=[2, 2, 2, 2])

# 替换为
self.encoder_sem = CLIPTraversabilityEncoder(
    clip_model="ViT-B/32",          # 冻结，不训练
    traversability_head=MLP(512, 256, 512),  # 只训练此部分
    text_conditioning=True          # 支持文本提示动态调节
)
```

输出维度保持 512，Decoder 完全不改动。

**文本提示动态调节代价权重：**

```python
# 推理时根据场景类型动态调节
text_prompt = "indoor office corridor"   # 或 "outdoor construction site"
clip_text_feat = clip.encode_text(text_prompt)
# 可通行性头以文本特征为条件，自适应调整各区域代价
```

**三步训练策略：**

1. 用现有语义代价图作为伪标签，预训练可通行性头
2. 接入 IL 训练，端到端微调可通行性头（CLIP 骨干冻结）
3. 接入 RL 微调，三个创新点形成完整流水线

### 评估

| 指标 | 方法 |
|---|---|
| 泛化性 | 训练时未见语义类别场景的成功率 |
| 代价预测质量 | 与人工标注代价图的相关系数 |
| 跨域迁移 | Matterport 训练 → Carla 测试的性能下降幅度 |

## 创新点 3：动态场景课程训练与能力验证

### 定位

创新点 1（RL 范式）在动态场景下的能力延伸。不引入新感知模块，通过课程式环境设计让策略隐式习得动态规避能力。

### 核心机制

深度图捕获"此刻障碍物在哪"，CLIP 特征识别"person"视觉模式，RL 训练将两者与规避行为绑定——无需跟踪和轨迹预测。

**Fear 信号自动升级：**

动态课程训练中，行人进入预测路径 → 代价激增 → Fear 标签=1 → BCE 损失反向传播。推理时 Fear 头自动响应动态障碍物，触发现有重规划机制。零新增模块。

### 课程设计

```
B1 纯静态环境          建立 RL 基础策略
        ↓ 成功率 > 80%
B2 慢速稀疏行人        1–2 个 agent，0.5m/s，固定轨迹
        ↓ 成功率 > 80%
B3 快速密集行人        3–5 个 agent，1.2m/s，随机轨迹
        ↓ 成功率 > 70%
B4 混合动态场景        行人 + 车辆，变速，双向行走
```

### 奖励函数扩展（B2 阶段起）

```
R_dynamic = R_创新点1原有项
           - λ · max(0, d_safe - d_pedestrian)   # λ=2.0, d_safe=0.8m
           - 5 · I(碰撞行人)                       # 碰撞终止 episode
```

### 评估体系

**仿真对比实验（完整统计）：**

| 指标 | 含义 |
|---|---|
| 动态场景成功率 | 不同行人密度下到达目标的比例 |
| 近距离事件率 | 轨迹中与行人距离 < 0.5m 的帧占比 |
| 路径效率退化 | 动态 vs 静态场景路径长度之比 |
| Fear 召回率 | 行人在预测路径上时 Fear=1 的比例 |
| 冻结率 | 机器人在人群中停止不动超过 5s 的比例 |

**消融实验：**

```
① IL-only（原版）              动态场景基准
② + RL 静态训练                验证 RL 本身的提升
③ + RL 动态课程（无 CLIP）     验证课程设计的必要性
④ + CLIP 语义（完整系统）      验证语义泛化的协同作用
```

**ANYmal 真机展示验证（非统计对比）：**

- 场景 1：单人横穿机器人前方
- 场景 2：人迎面走来
- 场景 3：多人走廊场景
- 形式：录制视频 + 记录 Fear 信号曲线

## 风险与 Fallback

| 创新点 | 主要风险 | Fallback |
|---|---|---|
| IL→RL | PPO 不收敛 | 改为自适应代价权重学习（仍在 IL 框架内） |
| CLIP 语义 | 泛化效果不显著 | 改为可学习语义权重（固定 CLIP，替换 MLP 结构） |
| 动态课程 | 课程跨度过大无法收敛 | 降低课程难度，仅验证 B2 阶段 |
| 真机验证 | 工程问题导致无法部署 | 以仿真结果为主，真机作为附录 |
